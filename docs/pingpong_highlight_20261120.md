# `pingpong_highlight.py` 物理抛物线轨迹优化与脚本问题修复说明（20261120）

- **日期**：`20261120`（2026-11-20）
- **涉及脚本**：`src/pingpong_highlight.py`（升级至 `v4.16`）
- **影响范围**：命令行流水线（`src/pingpong_highlight.py`、`src/run_pipeline.py`）与桌面端 WebUI（`webui/app/highlight_bridge.py` 动态加载同一脚本，自动同步生效）

## 一、背景与核心问题

在实际比赛录像推理中，检测模型（YOLO / RF-DETR / ONNX FP16）不可避免存在两类误差：
1. **空中离群误检**：球拍反光、球网白带、球员白鞋/球衣 Logo、邻台乒乓球等在 `1~3` 帧内被误识别为乒乓球；
2. **检测框中心抖动与短暂漏检**：高速运动模糊导致真实球框中心存在 `±3~8 px` 帧间抖动，或跨网/擦拍时短暂漏检。

旧版脚本在处理上述检测噪声时，会导致渲染出的球彗尾（残影）**突然出现尖锐折线、悬空横线甚至跨屏直线**，违背真实乒乓球在重力作用下的平滑抛物线轨迹。此外，在全面审查脚本时还发现了侧拍几何扭曲、跨缺口伪落点、分段特效串场等多项脚本级问题。

---

## 二、球轨迹“折线 / 非重力抛物线”五大根因与解决方案

### 1. 轨迹关联预测升级、多球台邻台隔离与多轨迹时序排他合并（`build_main_ball_track`）
- **原问题**：
  - 关联预测仅用最近 2 点做纯线性外推，未考虑重力下坠，且多帧缺口门限过大（1080p 下可达 `~300 px`），当前景球落网消失时极易跨空吸咐到背景隔壁台正在打的球并补帧拉出一条斜向长直线；
  - 若放宽包络框包含度（如 `overlap_self`），位于主球台画面正上方（挡板后方）的背景球台轨迹会完全落入主球台高抛大包络框内，在前景回合停顿期（如 `post-buffer`）混入残影；
  - 球网直线无限延伸导致背景球台过线也被计入 `net_cross_count` 获高倍加分；
  - **关键缺陷**：所有 `score >= 6.0` 的轨迹最后仅按单帧 `conf > main[fidx][2]` 混写入同一个字典，导致并发轨迹与真球主轨迹逐帧交替覆盖，产生剧烈锯齿折线。
- **修复方案**：
  - **四重隔壁球台隔离机制**：
    1. **邻台空域自动建模（`_extract_neighbor_table_zones`）**：从采样帧自动聚类提取非主球台的常驻背景台/侧边台及其上方挥拍空域，禁止非主台轨迹混入，并拦截前景轨迹跨缺口跳入邻台空域；
    2. **恢复严格 `IoU >= 0.15` + 主球台表面亲和与景深球径比校验**：移除易放行背景台的天空框包含度豁免，仅对真实触达主球台表面（`<=20px`）且球框短轴视直径比相符（`0.55x~1.85x`）的台内短快球豁免；全程远离主台面的背景台/近景角落台轨迹直接淘汰；
    3. **有限过网有效窗 + 跨缺口反重力上窜拦截**：`net_cross_count` 限制在主球台有效高度与宽度窗内；多帧缺口收紧预测容差，禁止非弹跳状态下向画面上方背景台跃迁；
    4. **时空交汇检验切断（`_split_switched_subsegs`）+ 补帧反重力拦截**：对缺口两侧子弧计算时空最小交汇距离 $\delta_{\text{meet}}$，一旦前景死网球与背景台球未能时空交汇则立即切断并剔除脱离主台的邻台段；`_ballistic_fill_gap` 对强反重力上窜缺口拒绝连线留白。
  - **时序排他认领**：预测步引入标定像素重力项 + 多步同向速度融合，合并阶段按轨迹得分由高到低时序排他认领，彻底杜绝并发轨迹逐帧穿插。

### 2. 像素重力自动标定（`estimate_gravity_px_per_frame2`）
- **方案**：
  - 利用球台透视四边形的对边向量与标准尺寸（$2.74\text{ m} \times 1.525\text{ m}$）反推中台像素比例尺 $\text{px/m}$ 及相机俯仰角余弦 $\cos\theta$，计算几何先验重力 $g_{\text{geo}} = \frac{9.81 \cdot s \cdot \cos\theta}{\text{fps}^2}$；
  - 自动扫描轨迹中单向、无弹跳的干净飞行窗口拟合二次项中位数，与几何重力融合得到自适应像素重力加速度 $g_{\text{frame}}$（$\text{px/帧}^2$）。

### 3. 双侧支撑物理抛物线离群点剔除（`clean_ball_track_parabolic`）
- **原问题**：进入 `main_track` 的 `1~3` 帧空中误检点及轨迹首尾误检点未被剔除，后续补帧又严格“钉死端点”，把误检尖刺直接固化成折角。
- **修复方案**：
  - **首尾孤立折钩裁剪**：检测每段首尾是否存在脱离内侧抛物线趋势的单帧反向折返或异常急坠（如遮挡后抓到球员白鞋 1 帧），优先裁除；
  - **双侧支撑（左右各 $\ge 2$ 点）Leave-Block-Out 抛物线桥接检验**：对长度 `w ∈ {1, 2, 3}` 的可疑块 $B$，用其前后紧邻支撑点集 $P_{\text{pre}} \cup P_{\text{post}}$ 拟合带重力约束的抛物线。若前后支撑点高度吻合**同一条自由飞行抛物线**，而 $B$ 显著偏离该抛物线，则判定为空中误检并摘除；
  - **物理安全性**：真实台面弹跳（下降转上升，单弧拟合需强反重力）与真实球拍击球（$v_x$ 反向）均无法由单条重力抛物线同时拟合前后支撑点，因此**真实弹跳与击球顶点 100% 不会被误删**。

### 4. 自由飞行子弧抛物线平滑与弹跳缺口解析补帧（`interpolate_track`）
- **原问题**：
  - 真实检测点存在 `±3~8 px` 框中心噪声，仅靠渲染时 3 点均值滤波仍呈折线；
  - 旧版 `_ballistic_fill_gap` 对反解重力 `a` 无上界约束（边界微抖即可导致过冲跑飞），`a <= 0`（如缺口内含弹跳）一律退化为悬空水平直线，且跨球拍击球反向缺口也会硬连斜直线。
- **修复方案**：
  - **接触断点与跨事件缺口切分**：自动识别显式击球折返点（`hit`）、台面弹跳极值点（`bounce`）以及缺口内发生弹跳/折返的边界，将轨迹切分为若干纯自由飞行子弧；
  - **有界重力抛物线平滑**：在每个自由飞行子弧内做闭式加权约束抛物线平滑（竖直加速度 $a_y \in [-0.18g,\, 3.0g]$ 兼顾强下旋飘球与强上旋暴冲，横向加速度受限防 S 形弯折），同时钉住弹跳与击球顶点（新增 `--no-track-smooth` 可选开关供对比排查）；
  - **分模式物理补帧**：
    1. **常规同弧缺口**：加速度钳制在 $[0.20g,\, 2.8g]$（无实测速度时取 $g$），严格过两端点且保持自然重力弧度；
    2. **缺口内含单次台面弹跳**：闭式求解线性弹跳时刻方程得到精确弹跳点 $(x_b, y_b)$，拼接落地前与弹起后两段重力抛物线，消除悬空水平弦；
    3. **跨击球反向缺口（$D \ge 3$）**：拒绝硬连斜直线，留白过渡。

### 5. 渲染端残影队列“幽灵点”修复与断续保护（`render` / `smooth_trail`）
- **原问题**：渲染循环中 `elif trail and len(trail) > 1: trail.popleft()` 导致缺口期间 `trail` 永远残留最后 1 个旧点；当球在另一侧重新出现时，新旧两点直接跨屏连成一条长直线。
- **修复方案**：
  - 缺口帧执行 `trail.popleft()` 直至彻底排空为 `0`；
  - 记录 `last_trail_f`，一旦帧号不连续（`f - last_trail_f > 1`）或位移超限，立即 `trail.clear()`，保证残影只在连续物理帧间绘制；
  - `smooth_trail` 改为轻量抛光核 `[0.15, 0.70, 0.15]` 并保护弹跳/击球尖点不被圆角削平悬空。

## 三、脚本层面一并修复的其他缺陷

1. **球台几何对边选择与侧拍沙漏扭曲修复（`extract_table_geometry`）**
   - 修复无球网或网线未穿过对边时，按单边角度排序（无网时全为 `90°`）必定误选**相邻两条边**作为对立短边的 bug，改为严格在两组对边 `(0,2)` 与 `(1,3)` 间择优；
   - 修复侧拍梯形球台因左右短边反向倾斜，独立按 `x` 排序把两条长边扭成对角相交沙漏形（bowtie）的问题，确保单应性矩阵 `H` 与走廊几何正确。
2. **侧拍视角走廊顶部开放坍缩修复（`build_corridor`）**
   - 修复 `open_top=True` 在侧拍/平视角下将右侧上下两个角同时钳到 `y = -10`、导致右半台走廊坍缩成斜楔形误筛真球的问题；现自动区分纵拍（沿侧边射线向顶延伸）与侧拍（抬升上侧长边至 `y = -10`，保留下侧长边拦截地面假球）。
3. **落点与击球事件检测修复（`detect_bounce_events`）**
   - 增加相邻轨迹点帧间隔校验，防止跨越未补帧长缺口（如两回合间隔数秒）误触发伪落点、伪击球与异常球速；
   - 将过短的 `1` 帧弹跳冷却调整为物理合理的 `0.12s`（至少 3 帧），防止单次弹跳平顶抖动在 2 帧内双计同侧落点而误触 `three_same_half` 提前结束回合；
   - 将击球事件（`"hit"`）的空间判定由桌面 `quad` 改为走廊区域 `_in_hit_zone`，修复选手在端线外挥拍扣杀无法触发 `FAST! / SMASH!` 特效的问题，并对单应性透视虚高球速（`> 165 km/h`）做上限保护。
4. **渲染架构去重、进度条、切段串场与内存泄漏修复（`render`）**
   - 合并前置精彩集锦与正片约 85 行重复渲染逻辑，补齐前置集锦渲染阶段的实时进度输出（解决 WebUI/CLI 开头进度长时间卡在 `0%` 的问题）；
   - 每个剪辑片段切换时自动清空残留粒子、浮动文字与闪屏状态，避免跨镜头特效串场；
   - 移除已停用绘制的 `shockwaves` 与 `bmarker` 每帧无界 `emit` 追加，消除列表内存泄漏；管道异常断开时先关闭 `stdin` 再等待退出以防死锁。
5. **收尾合成健壮性与 Windows 长滤镜兼容（`finalize_output`）**
   - 修复未安装 `ffmpeg` 时进入无音频分支仍调用 `ffmpeg` 抛出 `FileNotFoundError` 崩溃的问题；
   - 超多回合长视频的音频 `-filter_complex` 超过阈值时自动改写临时脚本走 `-filter_complex_script`，规避 Windows `CreateProcess` 32KB 命令行长度上限；
   - 前置集锦后的静音时长与取整黑幕帧数严格对齐，消除音画微偏。
6. **`.jsonl.gz` 压缩日志兼容与大视频常驻内存优化（`load_detections` / `main`）**
   - `load_detections` 原生支持读取 `.jsonl.gz`，且当传入 `.jsonl` 不存在而同名 `.jsonl.gz` 存在时自动回退读取（无缝衔接 WebUI 归档后的日志重跑）；
   - 加载时裁剪无关字段与未使用类别，并在提取完候选点后立即释放全量 `frames`，显著降低长视频渲染阶段内存占用；
   - 启动阶段提前创建输出目录，并升级 `_get_net_center_x` 为高置信度抽样中位数（不再二次扫盘取首帧无阈值框）。
7. **其他细节修正**
   - `filter_static_ball_candidates`：改为 50% 重叠滑动窗口 + 不同帧数校验，适度放宽静止微抖半径，消除固定窗口边界漏检；
   - `detect_rallies`：补齐无球网无落点回退分支缺失的 `duration` 与 `ended_reason` 字段；
   - `PlayerFX`：按帧率（`30.0 / fps`）归一化单帧位移阈值，使 30fps / 60fps / 120fps 光环响应一致；
   - 清理历史遗留死代码 `_greedy_match` 并修正 `--highlight-min-bounce-count` 帮助文案默认值描述。

## 五、验证摘要（20261120）

1. **自由飞行误检尖刺与平滑测试**：注入单帧横向往返尖刺、连续 2 帧遮挡误检块、反重力上跳尖刺及末端白鞋折钩后，离群帧 100% 被剔除；平滑补帧后相对真实重力抛物线均方根误差 `RMS = 1.33 px`（低于原始 `3.2 px` 高斯框抖动），无二阶差分突变折角。
2. **多拍复合技战术保护测试**：包含上旋快攻、两次台面弹跳、端线外挥拍击球、1 秒放高球（中间含空中误检尖刺）及下旋削球的完整回合中，空中尖刺被精准拔除，真实弹跳点与走廊击球点 100% 保留并准确检出。
3. **并发假轨迹与特殊缺口测试**：高置信度并发假球轨迹 0 帧渗入主轨迹；缺口内漏检的台面弹跳成功通过 `bounce_2arc` 双弧闭式还原落点深度；遮挡击球反向缺口正确留白不拉斜弦。
4. **WebUI 桥接端到端渲染测试**：自动回退读取 `.jsonl.gz`、自动创建不存在的输出子目录，跨越长缺口重现球体时画面中间区域无任何幽灵跨屏残影线。
