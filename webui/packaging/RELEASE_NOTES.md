## 🏓 乒乓彗星 TTComet v0.3.1

**把整场乒乓球录像自动剪成带特效的高光集锦**，无需安装 Python 或任何运行环境。

> v0.3.1 是 **v0.3.0 的修复版**：去水印改为在渲染特效之前处理源视频。
> 如果你会使用「去水印」，请务必升级；只做高光剪辑的用户不受影响。

### 本版修复

**去水印顺序修正（重要）**

v0.3.0 的去水印在成片之后执行，默认区域与右上角迷你球台 HUD 重叠，会把 HUD 顶部一起模糊；
自动检测还可能把常亮的 HUD 误判为水印。现在改为：

```text
推理 -> 去水印（源视频，生成 video_clean.mp4）-> 渲染特效 -> 去人声（仅音频）
```

- 迷你球台、雷达、连击面板、球轨迹等特效不再受影响；
- 自动检测在干净源视频上执行，不会被 HUD 干扰；
- WebUI 新增「去水印中」阶段，日志明确写出处理对象；
- 命令行流水线同步调整：`Step 2 去水印 → Step 3 高光`。

**代价**：去水印需要重编码整段源视频，46 分钟素材大约多花几分钟；只在勾选去水印时发生。

### 主要功能（与 v0.3.0 相同）

- **自动高光剪辑**：逐帧推理 → 球轨迹跟踪 → 回合检测 → 切片，自带球轨迹彗尾、落点标记、迷你球台、球员光环特效
- **可选清理**：去水印（默认方案 / 自动检测）与去人声（AI 分离 / 声道相减 / 静音），默认关闭
- **批量处理**：选择单个视频或整个文件夹，按文件名顺序跑完，模型只加载一次
- **中英双语界面**：右上角切换 中文 / English，参数说明与提示全部跟随
- **两档精度模型**：高精度（准）/ 低精度（快约 2.8 倍），运行时随时切换
- **参数可调**：10 组，每项都标注“调高/调低”的效果；支持保存多套自定义预设并重命名
- **检查更新**：启动自动检查 + 手动检查，发现新版可一键下载安装
- **不剪辑模式**：只加特效、保留完整时长，适合自己再剪
- **实时反馈**：进度条 + 日志流，结果可直接在线播放
- **输出目录可选**：留空就用默认目录，也可以指定任意文件夹（同名视频自动加序号，不覆盖）
- **处理记录**：每个视频自动落盘 `job.json`，刷新页面或重启程序后仍能看到历史
- **无控制台窗口**：双击启动不弹黑框；任务栏托盘图标可「打开界面 / 退出程序」

### 升级

直接运行新安装包覆盖安装即可。任务记录与成品保存在 `%LOCALAPPDATA%\TTComet\jobs\`，不受影响。

### 安装

- **不需要管理员权限**，默认安装到 `%LOCALAPPDATA%\Programs\TTComet`
- **内置 ffmpeg**，装完即用，不需要装 Python 或任何运行环境
- 安装完成后自动创建桌面快捷方式，可直接勾选启动
- 成品与处理记录保存在 `%LOCALAPPDATA%\TTComet\jobs\`
- 卸载不会删除任何历史任务与结果，便于换版本对比

### ⚠️ 关于“未签名”的安全提示（首次运行必看）

本程序**未做代码签名**（代码签名证书需要付费购买实名证书），因此部分电脑首次运行会弹出 Windows 安全提示：

> “Windows 已保护你的电脑” / “未知发布者”

这是未签名程序的正常提示，**不是病毒**。确认来源可信后可以：

1. 在提示窗口点 **“更多信息”**，再点 **“仍要运行”**
2. 或者先杀毒软件扫描安装目录，再启动程序

更稳妥的是：下载后核对下面的 SHA256 校验值，确认安装包完整、未被篡改：

```powershell
# 在下载目录执行，把文件名换成你下载的名字
certutil -hashfile TTComet-0.3.1-setup.exe SHA256
```

### 运行要求

- Windows 10 / 11（64 位）
- 推荐有独立显卡（AMD / NVIDIA）以启用 DirectML 加速；没有独显也能跑，速度会慢一些
- 硬盘建议预留 3 GB 以上可用空间（安装包包含 AI 去人声模型与中间文件）
- 检查更新与在线安装需要能访问 GitHub（只查询，不上传任何数据）
- 去人声的 AI 分离使用 CPU 推理，约 2 倍实时；DirectML 在部分显卡上输出不稳定，已默认关闭

### 已知限制

- 程序**未做代码签名**，首次运行会有 SmartScreen 提示（见上）
- 在线检查更新只查 GitHub；无法访问 GitHub 时不会提示新版本，可手动去 Releases 页面下载
- 去水印会重编码整段源视频，素材越长耗时越久
- 后处理与高光渲染都是同步执行，取消请求只能等当前步骤结束
- 自动检测只对「位置固定、亮度恒定」的叠加层有效，半透明/滚动水印检不出
- 同一时间只能处理一个任务（串行队列），避免多个任务争抢 GPU
