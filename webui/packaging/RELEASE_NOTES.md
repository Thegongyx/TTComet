## 🏓 乒乓彗星 TTComet v0.2.2

**把整场乒乓球录像自动剪成带特效的高光集锦**，无需安装 Python 或任何运行环境。

> v0.2.2 新增两项高光算法升级：
> **多机位 / 导播切视角自适应**（自动识别切镜、按机位重建球台几何、屏蔽特写/回放段）
> 和 **回合起点容错**（漏掉一侧落点时用「过网 + 活跃球」兜底开回合）。
> 普通固定单机位视频仍走原生管线，不改变既有效果。

### 主要功能

- **自动高光剪辑**：逐帧推理 → 球轨迹跟踪 → 回合检测 → 切片，自带球轨迹彗尾、落点标记、迷你球台、球员光环特效
- **批量处理**：选择单个视频或整个文件夹，按文件名顺序跑完，模型只加载一次
- **中英双语界面**：右上角切换 中文 / English，参数说明与提示全部跟随
- **两档精度模型**：高精度（准）/ 低精度（快约 2.8 倍），运行时随时切换
- **参数可调**：9 组 38 项，每项都标注“调高/调低”的效果；支持保存多套自定义预设并重命名
- **检查更新**：启动自动检查 + 手动检查，发现新版可一键下载安装
- **不剪辑模式**：只加特效、保留完整时长，适合自己再剪
- **实时反馈**：进度条 + 日志流，结果可直接在线播放
- **输出目录可选**：留空就用默认目录，也可以指定任意文件夹（同名视频自动加序号，不覆盖）
- **处理记录**：每个视频自动落盘 `job.json`，刷新页面或重启程序后仍能看到历史；被强行中断的任务标「已中断」
- **无控制台窗口**：双击启动不弹黑框；任务栏托盘图标可「打开界面 / 退出程序」

### 本版更新（相对 v0.2.1）

**1. 多机位 / 导播切视角自适应（第一阶段，默认 `auto`）**

- 自动从检测日志识别导播切镜：区分不同球台机位与**无球台特写 / 观众 / 慢放过场**镜头；
- 每个机位独立拟合 `quad / net_line / corridor / homography / neighbor_zones`，不再用全片一套几何；
- 按镜头（Shot）隔离执行走廊过滤、轨迹关联、重力标定、抛物线净化、补帧与落点检测：
  跨镜头不插值、不拉直线，切镜边界也不再出现横穿画面的残影；
- 跨焦段球速按像素比例尺归一化，前置精彩回合的球速排序跨镜头可比；
- 回合中途切球台机位保持不断裂；切入球员特写时干净收尾；渲染遇切镜帧立即清空残影 / 粒子 / 选手光环；
- 固定单机位视频带三重保护（半遮挡钉边、静止球网、同帧共存邻台），仍走原生单机位管线；
- 新增参数 `--camera-mode auto / single / multi`（默认 `auto`）。

**2. 回合起点容错（默认 `auto`）**

- 近台落点漏检导致“两半台落点凑不齐”时，不再直接丢失回合：
  若最近 0.32s 真实球检测充分、球速高于慢速阈值 ×1.5、球在走廊内，且明确越过球网，
  则从过网前 `PRE_ROLL` 处开回合；
- 起点自动 clamp 到**上一回合结束 +1.5s**、当前镜头起点、最近切镜帧之后；
- 要求最近 2s 内有过落点，且开回合后至少出现一次落点确认，避免捡球 / 滚球误入；
- 球网附近 4% 网长死区，避免球贴网线抖动误触发；切镜后 0.2s 内不触发；
- 实测 46 分钟样本：回合 76 → 86，有效片段 36 → 44，最后一分由“缺失”变为进入成片，
  原有 76 个回合 **0 丢失**；
- 参数：`--rally-start auto`（默认）/ `--rally-start bounce`（旧行为）。

**3. 流水线与参数**

- `run_pipeline.py` 补齐 `--out-of-table-timeout / --no-bounce-timeout / --rally-lost-timeout / --table-edge-tol`，
  并支持把未识别参数透传给高光脚本，后续新增高光参数不必同步改流水线；
- WebUI「轨迹 / 回合」组新增「回合起点判定」下拉框，默认「落点 + 过网兜底」；
- 高光脚本升级到 **v4.19**（多机位分段几何 + 回合起点过网兜底）。

### 安装

- **不需要管理员权限**，默认安装到 `%LOCALAPPDATA%\Programs\TTComet`
- **内置 ffmpeg**，装完即用，不需要装 Python 或任何运行环境
- 安装完成后自动创建桌面快捷方式，可直接勾选启动
- 成品与处理记录保存在 `%LOCALAPPDATA%\TTComet\jobs\`
- 卸载不会删除任何历史任务与结果，便于换版本对比

### ⚠️ 关于“未签名”的安全提示（首次运行必看）

本程序**未做代码签名**（代码签名证书需要付费购买实名证书），因此部分电脑首次运行会弹出 Windows 安全提示：

> “Windows 已保护你的电脑” / “未知发布者”

这是未签名程序的正常提示，**不是病毒**。确认来源可信后可以：

1. 在提示窗口点 **“更多信息”**，再点 **“仍要运行”**
2. 或者先杀毒软件扫描安装目录，再启动程序

更稳妥的是：下载后核对下面的 SHA256 校验值，确认安装包完整、未被篡改：

```powershell
# 在下载目录执行，把文件名换成你下载的名字
certutil -hashfile TTComet-0.2.2-setup.exe SHA256
```

### 运行要求

- Windows 10 / 11（64 位）
- 推荐有独立显卡（AMD / NVIDIA）以启用 DirectML 加速；没有独显也能跑，速度会慢一些
- 硬盘建议预留 2 GB 以上可用空间（成品目录、视频转换、中间文件）
- 检查更新与在线安装需要能访问 GitHub（只查询，不上传任何数据）

### 已知限制

- 程序**未做代码签名**，首次运行会有 SmartScreen 提示（见上）
- 在线检查更新只查 GitHub；无法访问 GitHub 时不会提示新版本，可手动去 Releases 页面下载
- 多机位识别为第一阶段：极端变焦、强遮挡或背景邻台仍可能被误判为独立机位；
  建议先在目标素材上跑一版，确认切镜分段符合预期
- 过网开回合可能在热身 / 连续捡球时多开短回合；这些片段通常会被有效回合门槛过滤，
  如出现误入可改用 `--rally-start bounce` 或收紧参数
- 同一时间只能处理一个任务（串行队列），避免多个任务争抢 GPU
