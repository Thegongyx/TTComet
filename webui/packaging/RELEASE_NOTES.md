## 🏓 乒乓彗星 TTComet v0.2.1

**把整场乒乓球录像自动剪成带特效的高光集锦**，无需安装 Python 或任何运行环境。

> v0.2.1 新增**在线检查更新**：启动时自动检查一次，也可以手动点「检查更新」；
> 发现新版本后可一键下载并启动安装程序，不用再去网页找下载链接。
> 高光算法沿用 v0.2.0（重力抛物线净化与平滑、多球台邻台球隔离、残影时长可调）。

### 主要功能

- **自动高光剪辑**：逐帧推理 → 球轨迹跟踪 → 回合检测 → 切片，自带球轨迹彗尾、落点标记、迷你球台、球员光环特效
- **批量处理**：选择单个视频或整个文件夹，按文件名顺序跑完，模型只加载一次
- **中英双语界面**：右上角切换 中文 / English，参数说明与提示全部跟随
- **两档精度模型**：高精度（准）/ 低精度（快约 2.8 倍），运行时随时切换
- **参数可调**：9 组 37 项，每项都标注"调高/调低"的效果；支持保存多套自定义预设并重命名
- **检查更新**：启动自动检查 + 手动检查，发现新版可一键下载安装
- **不剪辑模式**：只加特效、保留完整时长，适合自己再剪
- **实时反馈**：进度条 + 日志流，结果可直接在线播放
- **输出目录可选**：留空就用默认目录，也可以指定任意文件夹（同名视频自动加序号，不覆盖）
- **处理记录**：每个视频自动落盘 `job.json`，刷新页面或重启程序后仍能看到历史；被强行中断的任务标「已中断」
- **无控制台窗口**：双击启动不弹黑框；任务栏托盘图标可「打开界面 / 退出程序」

### 本版更新（相对 v0.2.0）

**1. 启动时自动检查更新**

- 只查询 GitHub Releases（`TheGongyx/TTComet`），不使用其他更新源
- 查询成功缓存 6 小时、失败缓存 30 分钟，超时 5 秒；断网、被墙时静默失败，不影响正常出片
- 界面状态栏右侧新增「检查更新」按钮，可随时手动查询

**2. 一键下载并安装**

- 发现新版本后弹出提示条：版本号对比 + 「下载并安装」+「更新说明」+ 关闭
- 下载在后台线程进行，界面显示百分比与已下载/总大小（约 244 MB）
- 下载地址限定 GitHub 域名（含重定向后的 release-assets 域名），避免被篡改为第三方链接
- Release 若提供 `sha256` 摘要会自动校验，校验失败会删除文件并提示重试
- 下载完成后点「立即安装」：启动安装包并自动退出本程序，避免安装时文件被占用；
  任务运行期间拒绝安装，防止打断出片

**3. 其它**

- 版本号统一到 0.2.1；「关于/页脚」版本号来自后端 `APP_VERSION`，升级后自动更新
- 高光脚本仍为 v4.17（与 0.2.0 相同）

### 安装

- **不需要管理员权限**，默认安装到 `%LOCALAPPDATA%\Programs\TTComet`
- **内置 ffmpeg**，装完即用，不需要装 Python 或任何运行环境
- 安装完成后自动创建桌面快捷方式，可直接勾选启动
- 成品与处理记录保存在 `%LOCALAPPDATA%\TTComet\jobs\`
- 覆盖安装即可升级，历史任务与预设保留

### 🛡️ 关于"未签名"的安全提示（首次运行必看）

本程序**未做代码签名**（代码签名证书需要付费购买实名证书），因此部分电脑首次运行会出现 Windows 防护提示：

> "Windows 已保护你的电脑" / "未知发布者"

这是未签名程序的正常提示，**不是病毒**。想继续使用可以：

1. 在提示窗口点 **"更多信息"**，再点 **"仍要运行"**
2. 或在杀毒软件里把安装目录加入白名单后重试

若有疑虑，可以用下面的 SHA256 校验值核对安装包是否完整、未被篡改：

```powershell
# 在下载目录执行，把结果与下面两行对比

```

### 运行要求

- Windows 10 / 11（64 位）
- 推荐有独立显卡（AMD / NVIDIA 均可，走 DirectML 加速）；没有独显也能跑，速度会明显更慢
- 磁盘建议预留 2 GB 以上可用空间（成品目录、视频转码与中间文件）
- 检查更新与自动下载需要能访问 GitHub（本程序只查询、不上传任何数据）

### 已知限制

- 程序**未做代码签名**，见上方说明
- 更新检查只走 GitHub：无法访问 GitHub 时不会提示新版本，可手动到 Releases 页面下载
- 下载与安装不是"静默自动更新"：安装程序会正常弹出向导，需要点几下完成
- 同一时间只能处理一个任务（串行队列，避免争抢 GPU）
- 批处理多个视频时是串行的：推理 → 高光 → 下一个，不会并行占满 GPU/CPU
- 暂不支持手动选择 GPU 型号，由 DirectML 自动挑选
- 处理记录只保留最近 80 条；日志只存在于内存中，任务结束后不落盘

### 技术说明

- 推理使用 ONNX Runtime（DirectML / CPU 自动回退），不依赖 PyTorch / ultralytics
- 高光剪辑逻辑与仓库里的 `src/pingpong_highlight.py` 完全同源（当前 v4.17），运行时直接加载该脚本
- 更新检查用标准库 `urllib` 访问 GitHub API（无额外依赖），结果在内存中缓存
- 两档模型单帧推理：高精度约 20.5 ms/帧，低精度约 7.4 ms/帧（同一台机器实测）
