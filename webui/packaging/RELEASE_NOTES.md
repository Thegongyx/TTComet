## 🏓 乒乓彗星 TTComet v0.2.0

**把整场乒乓球录像自动剪成带特效的高光集锦**，无需安装 Python 或任何运行环境。

> v0.2.0 重点升级高光算法（脚本 v4.15 → v4.17）：球轨迹按真实重力抛物线净化与平滑，
> 误检造成的尖刺折线与跨缺口直线基本消失；多球台场景下隔壁台的球不会再串进主轨迹；
> 新增「球残影时长」参数（默认 0.3 秒，旧版固定 0.2 秒）。

### 主要功能

- **自动高光剪辑**：逐帧推理 → 球轨迹跟踪 → 回合检测 → 切片，自带球轨迹彗尾、落点标记、迷你球台、球员光环特效
- **批量处理**：选择单个视频或整个文件夹，按文件名顺序跑完，模型只加载一次
- **中英双语界面**：右上角切换 中文 / English，参数说明与提示全部跟随
- **两档精度模型**：高精度（准）/ 低精度（快约 2.8 倍），运行时随时切换
- **参数可调**：9 组 37 项，每项都标注"调高/调低"的效果；支持保存多套自定义预设并重命名
- **不剪辑模式**：只加特效、保留完整时长，适合自己再剪
- **实时反馈**：进度条 + 日志流，结果可直接在线播放
- **输出目录可选**：留空就用默认目录，也可以指定任意文件夹（同名视频自动加序号，不覆盖）
- **处理记录**：每个视频自动落盘 `job.json`，刷新页面或重启程序后仍能在「③ 处理」里看到历史；被强行中断的任务标「已中断」
- **无控制台窗口**：双击启动不弹黑框；任务栏托盘图标可「打开界面 / 退出程序」

### 本版更新（相对 v0.1.1）

**1. 球轨迹：物理重力抛物线净化 + 平滑（核心）**

- 由球台四角自动标定像素重力加速度（px/帧²），轨迹关联不再依赖纯线性外推
- 剔除 1~3 帧的空中误检（球拍反光、白鞋、球台白带、灯管反光等），且不会误删真实弹跳点与击球顶点
- 自由飞行段按有界重力抛物线平滑，弹跳/击球点钉死，残影不再出现尖锐折线与悬空横线
- 缺口补帧分三档：常规同弧弹道、缺口内含台面弹跳的双弧闭式还原、跨击球反向缺口留白（不再硬连斜直线）

**2. 多球台邻台球隔离**

- 自动识别非主球台的常驻空域（背景台/侧边台），邻台的独立球轨迹直接淘汰
- 缺口预测收紧并加入时空交汇检验：前景落网球不会被"吸"到背景台正在打的球上
- 拦截非弹跳状态下的反重力上窜缺口，补帧阶段不再跨空拉长线

**3. 新增「球残影时长（秒）」参数**

- 默认 **0.3 秒**（旧版固定 0.2 秒），可调 0~2 秒；设为 0 关闭残影
- 命令行对应 `--trail-sec`，WebUI 在「视觉效果」组里直接调

**4. 其它修复**

- 球台对边选择（无球网时误选相邻边）、侧拍视角走廊顶部坍缩
- 落点/击球误判：跨长缺口伪落点、1 帧弹跳双计、端线外挥拍不触发击球、单应性球速虚高
- 分段切换时清空残留粒子/文字/闪屏，避免跨镜头特效串场
- 未安装 ffmpeg 时不再崩溃；超多回合长视频规避 Windows 32KB 命令行上限
- 支持直接读取归档后的 `.jsonl.gz` 检测日志；长视频渲染阶段内存占用显著下降

### 安装

- **不需要管理员权限**，默认安装到 `%LOCALAPPDATA%\Programs\TTComet`
- **内置 ffmpeg**，装完即用，不需要装 Python 或任何运行环境
- 安装完成后自动创建桌面快捷方式，可直接勾选启动
- 成品与处理记录保存在 `%LOCALAPPDATA%\TTComet\jobs\`

### 📦 分卷下载（Gitee 附件单文件限制 100 MB）

> **最省事的方式**：从 GitHub 直接下载完整安装包，不用合并：
> https://github.com/Thegongyx/TTComet/releases/download/v0.2.0/TTComet-0.2.0-setup.exe

**Gitee 单个附件不能超过 100 MB**，所以 Gitee 上的安装包被切成 3 个分卷，需要全部下载后合并：

1. 把 `TTComet-0.2.0-setup.exe.part1 / .part2 / .part3` 下载到**同一目录**
2. 在该目录打开命令行（地址栏输入 `cmd` 回车），执行：

```
copy /b TTComet-0.2.0-setup.exe.part1 + TTComet-0.2.0-setup.exe.part2 + TTComet-0.2.0-setup.exe.part3 TTComet-0.2.0-setup.exe
```

3. 得到完整的 `TTComet-0.2.0-setup.exe`，双击安装

合并完成后校验 SHA256，应与上面列出的值一致。

### 运行要求

- Windows 10 / 11（64 位）
- 推荐有独立显卡（AMD / NVIDIA 均可，走 DirectML 加速）；没有独显也能跑，速度会明显更慢
- 磁盘建议预留 2 GB 以上可用空间（成品目录、视频转码与中间文件）

### 已知限制

- 程序**未做代码签名**，见上方说明
- 同一时间只能处理一个任务（串行队列，避免争抢 GPU）
- 批处理多个视频时是串行的：推理 → 高光 → 下一个，不会并行占满 GPU/CPU
- 暂不支持手动选择 GPU 型号，由 DirectML 自动挑选
- 处理记录只保留最近 80 条；日志只存在于内存中，任务结束后不落盘

### 技术说明

- 推理使用 ONNX Runtime（DirectML / CPU 自动回退），不依赖 PyTorch / ultralytics
- 高光剪辑逻辑与仓库里的 `src/pingpong_highlight.py` 完全同源（当前 v4.17），运行时直接加载该脚本
- 两档模型单帧推理：高精度约 20.5 ms/帧，低精度约 7.4 ms/帧（同一台机器实测）
